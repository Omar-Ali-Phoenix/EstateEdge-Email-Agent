# Web assets

The four brand files below are the original submission's assets. They are
binary and the deploy script uploads them automatically if present:

- `logo.png`
- `favicon.ico`
- `favicon-32.png`
- `apple-touch-icon.png`

To use your own brand instead, just replace the files with ones of the same
name and dimensions, or update the `<img>`/`<link>` tags in `web/index.html`.
